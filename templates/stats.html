To describe these constructions, the database contains {{ counter }} RDF triplets. The A-box is stored in three separate files. One file (cx.ttl) stores information about the constructions and contains {{ counter_cx }} RDF triplets, one (membr.ttl) stores information about the researchers and their research and contains {{ counter_membr }} RDF triplets, and the last one (references.ttl) stores the bibliography and contains {{ counter_references }} RDF triplets.
